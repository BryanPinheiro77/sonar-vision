# Política de segurança

## Estado do projeto

O Sonar Vision está em desenvolvimento inicial e ainda não possui uma versão
estável suportada. Não utilize o projeto como único recurso de mobilidade,
segurança ou orientação.

## Como relatar uma vulnerabilidade

Não publique em uma issue aberta vulnerabilidades que exponham credenciais,
dados pessoais, formas de comprometer dispositivos ou instruções de exploração.

Relate o problema de forma privada aos mantenedores pelos dados de contato
publicados no [perfil do responsável pelo repositório](https://github.com/BryanPinheiro77).
Inclua, quando possível:

- componente e revisão afetados;
- descrição do impacto;
- passos mínimos para reprodução;
- logs sem credenciais ou dados pessoais;
- mitigação sugerida, se conhecida.

O recebimento será confirmado assim que possível. Antes de uma versão estável,
os prazos de análise e correção são de melhor esforço e serão comunicados no
próprio contato privado.

## Escopo

São especialmente relevantes falhas que afetem o caminho tátil local,
integridade de comandos, autenticação, transporte de frames, atualização de
firmware, privacidade de imagens ou disponibilidade do dispositivo.

Dependências de terceiros devem ser relatadas também ao mantenedor original,
seguindo a política daquele projeto.
